# Eksamen i PRO105 Kreativt webprosjekt høsten 2023
> Fra 17.11.2023 kl. 10:00 til 01.12.2023 kl. 15:00
> 
> **Karakter: Bestått** (Bestått / Ikke bestått)

Dette er min gruppebesvarelse på eksamen i PRO105 Kreativt webprosjekt ved Høyskolen Kristiania høsten 2023 (1. semester i utdanningen). 

Vi var 5 studenter på gruppe (meg, Paal Fredrik Nybø, Miriam Fosmark Haugland, Storm Julian Thorsen og William Dahl) som alle kodet og animerte en side hver.

Min side var side 3 (bryllup i Las Vegas).

Det var kun lov til å bruke ren HTML5 og CSS3, ikke Javascript eller andre rammeverk (dette ville gitt automatisk stryk).

-----

Forelesere i faget var [Alexander Sundli-Härdig](https://www.linkedin.com/in/asundlihardig/) (HTML og CSS) og [Terje Idland](https://www.linkedin.com/in/terje-idland-b474a282/) (kreative prosesser).
